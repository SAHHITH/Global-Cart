# Global Cart — Modern E-Commerce Frontend

Global Cart is a frontend-only marketplace application built with React, Vite, Tailwind CSS, shadcn/ui primitives, Material UI, Ant Design, Zustand, Framer Motion, and Recharts.

## Features
- **Global Cart & Wishlist Management:** Persisted in `localStorage` via Zustand with quantity controls, coupon codes, and instant slide-out drawer.
- **Theme System:** Light, Dark, and System theme modes synced across Tailwind CSS, CSS Custom Properties, Material UI, and Ant Design.
- **Product Discovery:** Multi-criteria filtering (category, price range, rating, brand, stock), sorting, quick-view modal, and search results.
- **Admin Dashboard:** Interactive sales, category revenue, and catalog management views powered by Recharts and Ant Design.
