# Product Design Requirements (PDR) — Global Cart

1. **Architecture:** 100% client-side SPA using React Router DOM v7 and Zustand stores persisted to browser `localStorage`.
2. **Core Components (17):** Header, Navbar, HeroSection, CategorySection, ProductCard, ProductGrid, ProductFilters, ProductSort, ProductDetails, CartDrawer, CartSummary, WishlistButton, DealOfTheDay, ThemeToggle, Footer, Checkout, AdminDashboard.
3. **Catalog:** 32 structured mock products across Electronics, Fashion, Home & Kitchen, Beauty, Sports, and Accessories.
